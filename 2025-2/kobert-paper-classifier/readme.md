# 学術論文 研究分野自動分類モデル（KoBERTベース）

論文のタイトル（title）と要旨（abstract）を入力として受け取り、5つの研究分野 — `農学`、`社会福祉学`、`社会学`、`電子/情報通信工学`、`工学一般` — のいずれかに自動分類するテキスト分類モデルです。

## 1. 課題定義

学術データが爆発的に増加する中、大量の論文を体系的に分類する自動化システムの必要性が高まっています。本プロジェクトは、論文のタイトルと要旨のテキストのみから、5つの研究分野を自動分類するモデルを構築することを目的としています。

K-NNのような単語頻度ベースのモデルは、「社会福祉」の"社会"と「社会階層」の"社会"を区別できません。一方、BERTは文全体を双方向に読み込んで文脈を学習するため、"社会"の周辺に「政策」「児童」があれば`社会福祉学`、「権力」「階層」があれば`社会学`と判別できます。この理由から、BERT系モデルを採用しました。

## 2. 参考文献とモデル選定プロセス

| 参考論文 | 主な内容 | 本プロジェクトへの適用点 |
|---|---|---|
| 韓国語特許文に基づくCPC自動分類研究 | KorPatBERTを用いて特許文書をCPCに分類、特許ドメインにおいてGoogle BERTより4.5%の性能向上。ドメイン特化型BERT＋分類器の組み合わせが専門テキスト分類に有効であることを実証 | ドメイン特化型事前学習モデル＋分類器の組み合わせ構造 |
| KorPatBERTベースのCPC分類モデルを活用した韓国語特許文献検索性能向上研究 | BM25より高い性能。トークン長を伸ばしても性能向上はわずか（文書の主要情報は主に前半にあるため）→軽量なIR-SC256モデルを採用。Class WeightingとEarly Stoppingでデータ不均衡・過学習に対応 | Class Weighting、Early Stoppingの適用 |

KorPatBERTはオープンソースではなく、権利者からの別途ライセンス許可が必要で、コンペ期間中に使用許可を取得できず、テストできませんでした。そのため、オープンソースかつ韓国語特化型モデルであるKoBERTを最終的に採用しました。

### モデル比較

| | BERT | KorPatBERT | KoBERT |
|---|---|---|---|
| 開発元 | Google AI | 韓国特許情報院 | SKT Brain |
| 公開状況 | オープンソース | ライセンス許可が必要 | オープンソース |

| 長所 | 英語基準で最も広く使われる基本モデル、多数の派生モデルの基盤 | 特許文の表現・専門用語の理解に強い | 韓国語トークナイザー・コーパスで学習、オープンソースの中では韓国語一般ドメイン性能が優秀 |

一般的な学術論文の分野分類には、KoBERTが最も適していると判断し、ベースモデルとして選定しました。

## 3. 最終採用モデル：KoBERT

KoBERTは、SKT Brainが開発した韓国語専用のBERT言語モデルです。Google BERTと同じエンコーダベースのTransformer構造を使用していますが、英語・多言語ではなく韓国語データのみで事前学習されているため、韓国語の文脈と意味をより正確に理解できます。

KoBERTはWikipediaやニュースなどから収集した数百万の韓国語文で学習されており、韓国語の不規則な語尾・助詞を反映するため、データベースのトークン化手法を採用しています。これにより、既存モデルより約27%少ないトークン数で約2.6%高い性能を出すと報告されています。

本プロジェクトでは、このKoBERTの上にシンプルな分類器を載せ、論文の要旨のみから専攻分野を自動分類するために活用しました。

## 4. 使用ライブラリ

- Transformers：`AutoTokenizer`でKoBERTに対応したトークナイザーを自動選択し、テキストをモデル入力形式に変換。KoBERTモデルの読み込み・学習・評価・重み保存までを担うフレームワーク
- KoBERTモデル：事前学習済みの重みを読み込み、最後の出力層のみ5つの専攻分野カテゴリに合わせて修正して学習。入力文を分野ごとの確率を出力する分類器として設計
- トークナイザー：文をサブワード単位に分割し、KoBERTの語彙IDに変換する前処理エンジン。論文タイトルと要旨を`[SEP]`トークンで連結し、モデルが2つの情報を同時に見つつも別々の塊として認識できるように構成

## 5. プロジェクト実行フロー
<img width="1600" height="900" alt="image" src="https://github.com/user-attachments/assets/aa7ccb02-26bf-4eb2-b6fa-c10dd7cf3614" />

1. テキスト前処理：`タイトル + [SEP] + 要旨`の形式で結合。タイトルは論文の核心テーマを、要旨は内容・方法・結果を含むため、両方の情報を同時に活用して分野をより正確に分類できるよう設計
2. トークナイズ：文をKoBERTの語彙IDに変換。同時に分野ラベルを0〜4の整数にカテゴリ化
3. 学習：KoBERTの事前学習済み重みを読み込み、5ニューロンの出力層を追加。データ数が相対的に少ない`社会学`分野にはクラス重み付けを適用し、データ不均衡を補正。Early Stopping（patienceベース）で過学習を防止
4. 性能評価：別途分離した検証データに対して予測を実行し、Accuracy、F1スコア、Recallを計算。これらの指標を比較し、最も性能の良いエポックのモデルを最終モデルとして選定

## 6. 最終性能

| 指標 | 学習（Train） | 検証（Validation） |
|---|---|---|
| Accuracy | 0.9690 | 0.9691 |
| Loss | - | 約0.03 |
| Macro F1 | - | 0.956 |

学習・検証データの正解率がそれぞれ0.9690、0.9691とほぼ同一の値となり、過学習のパターンは観察されませんでした。 全サンプルのうち約3%のみが誤分類された水準です。

### クラス別の特徴

- 社会学分野が最も低い性能（正解率約89%）を示しましたが、実運用が不可能なレベルではありません。原因は他分野に比べて学習データ数が少ないことと推定され、データを追加確保すれば性能改善の余地があります。
- 混同行列（Confusion Matrix）上では、`社会福祉学`と`社会学`間の誤分類が目立ちますが、両分野のテーマ・キーワードが類似しているため、モデルにとっても区別が難しいと分析しました。

> 参考：別途再現した学習実行（`classification_report.csv`基準）では、Accuracy 0.9597、Macro F1 0.9448という結果になりました。発表時点のモデル（Accuracy 0.9691、Macro F1 0.956）とわずかな差がありますが、ランダムシード・データ分割・エポック選定の違いによる再現時のばらつきと考えられます。実際の値は各実行結果ファイルを基準に記載してください。

## 7. 今後の課題

- `社会学`分野のデータ追加確保によるクラス不均衡の緩和
- KorPatBERTのライセンス取得後、ドメイン特化型モデルとの再比較

# 학술논문 연구분야 자동 분류 모델 (KoBERT 기반)

논문의 제목(title)과 초록(abstract)을 함께 입력받아, 5개 연구분야 — `농학`, `사회복지학`, `사회학`, `전자/정보통신공학`, `공학일반` — 중 하나로 자동 분류하는 텍스트 분류 모델입니다.

## 1. 문제 정의

학술 데이터가 폭발적으로 증가하면서, 방대한 논문을 체계적으로 분류하는 자동화 시스템의 필요성이 커지고 있습니다. 이 프로젝트는 논문의 제목과 초록 텍스트만으로 5개 연구분야를 자동 분류하는 모델을 만드는 것을 목표로 합니다.

K-NN 같은 단어 빈도수 기반 모델은 "사회복지"의 '사회'와 "사회계층"의 '사회'를 구분하지 못합니다. 반면 BERT는 문장을 양방향으로 읽어 문맥을 학습하기 때문에, '사회' 주변에 '정책'·'아동'이 오면 `사회복지학`으로, '권력'·'계층'이 오면 `사회학`으로 구분할 수 있습니다. 이런 이유로 BERT 계열 모델을 채택했습니다.

## 2. 참고 문헌 및 모델 선택 과정

| 참고 논문 | 핵심 내용 | 이 프로젝트에 적용한 부분 |
|---|---|---|
| 한국어 특허 문장 기반 CPC 자동분류 연구 | KorPatBERT로 특허 문서를 CPC로 분류, 구글 BERT보다 특허 도메인에서 4.5% 성능 향상. 도메인 특화 BERT + 분류기 결합이 전문 텍스트 분류에 효과적임을 입증 | 도메인 특화 사전학습 모델 + 분류기 결합 구조 |
| KorPatBERT 기반 CPC 분류 모델을 활용한 특허 문헌 검색 성능 향상 연구 | BM25보다 높은 성능. 토큰 길이를 늘려도 성능 향상은 미미(문서 핵심 정보는 주로 앞부분에 위치) → 가벼운 IR-SC256 모델 채택. Class Weighting과 Early Stopping으로 데이터 불균형·과적합 대응 | Class Weighting, Early Stopping 적용 |

KorPatBERT는 오픈소스가 아니며 저작권자의 별도 라이선스 허가가 필요해, 대회 기간 내 사용 권한을 발급받지 못해 테스트하지 못했습니다. 이에 따라 오픈소스이자 한국어 특화 모델인 KoBERT를 최종 채택했습니다.

### 모델 비교
<img width="1600" height="900" alt="image" src="https://github.com/user-attachments/assets/362566e1-c264-43eb-8be3-6f7ca056c8fe" />

| | BERT | KorPatBERT | KoBERT |
|---|---|---|---|
| 제작사 | 구글 AI | 한국특허정보원 | SKT Brain |
| 공개 여부 | 오픈소스 | 라이선스 허가 필요 | 오픈소스 |
| 학습 데이터 | 영어 위키피디아, BookCorpus | 국내 특허 문헌 약 406만 건 | 한국어 위키 + 한국어 말뭉치 수백만 문장 |
| 장점 | 영어 기준 가장 널리 쓰이는 기본 모델, 다양한 파생 모델의 기반 | 특허 문장·전문 용어 이해에 강함 | 한국어 토크나이저·말뭉치로 학습, 오픈소스 중 한국어 일반 도메인 성능 우수 |
| 단점 | 한국어 데이터 거의 없어 한국어 작업에 부적합 | 특허 외 일반 도메인(뉴스, 일상 문장)에서 성능 저하 가능 | 특허·법률처럼 극도로 전문적인 텍스트에서는 KorPatBERT에 비해 도메인 갭 존재 |

일반 학술 논문 분야 분류에는 KoBERT가 가장 적합하다고 판단해 기본 모델로 선택했습니다.

## 3. 최종 채택 모델: KoBERT

KoBERT는 SKT Brain이 개발한 한국어 전용 BERT 모델입니다. 구글 BERT와 동일한 인코더 기반 Transformer 구조를 쓰지만, 한국어 데이터만으로 사전학습되어 한국어 문맥·의미를 더 잘 이해합니다. 한국어 불규칙 어미·조사를 반영한 데이터 기반 토큰화 기법을 사용해, 기존 모델보다 약 27% 적은 토큰 수로도 약 2.6% 높은 성능을 낸다고 보고되어 있습니다.

본 프로젝트에서는 KoBERT 위에 5개 분야용 분류기(출력층)를 얹어, 논문 제목+초록만으로 전공 분야를 자동 분류하도록 구성했습니다.

## 4. 사용 라이브러리

- Transformers: `AutoTokenizer`로 KoBERT용 토크나이저를 자동 선택하고, 텍스트를 모델 입력 형식으로 변환. KoBERT 모델을 불러와서 학습·평가·가중치 저장까지 담당하는 프레임워크
- KoBERT 모델: 사전 학습된 가중치를 불러와 마지막 출력층만 5개 카테고리에 맞게 교체 학습. 입력 문장을 벡터로 압축해 각 분야에 속할 확률을 출력
- 토크나이저: 문장을 서브워드 단위로 쪼개 토큰 ID로 변환하는 전처리 엔진. 제목과 초록을 `[SEP]` 토큰으로 이어붙여 모델이 두 정보를 함께 보면서도 서로 다른 덩어리로 인식하도록 구성

## 5. 프로젝트 진행 흐름
<img width="1600" height="900" alt="image" src="https://github.com/user-attachments/assets/aa7ccb02-26bf-4eb2-b6fa-c10dd7cf3614" />

1. 텍스트 전처리: `제목 + [SEP] + 초록` 형태로 결합. 제목은 핵심 주제, 초록은 내용·방법·결과를 담아 두 정보를 함께 활용
2. 토크나이징: 문장을 KoBERT 단어사전 ID로 변환, 라벨을 0~4 정수로 인코딩
3. 학습: KoBERT 사전학습 가중치 로드 + 5개 뉴런 출력층 추가. 데이터가 적은 `사회학` 분야에 Class Weighting 적용, Early Stopping(patience 기반)으로 과적합 방지
4. 성능 평가: 검증 데이터에 대해 Accuracy, F1, Recall 계산 후 가장 성능이 좋은 epoch을 최종 모델로 선정

학습/검증 정확도가 0.9690 vs 0.9691로 거의 동일해 과적합 패턴은 관찰되지 않았습니다. 전체 샘플 중 약 3%만 오분류한 수준입니다.

### 클래스별 특이사항

- 사회학 분야가 가장 낮은 성능(정답률 약 89%)을 보였지만, 실사용이 불가능한 수준은 아닙니다. 원인은 다른 분야보다 학습 데이터 수가 적기 때문으로 추정되며, 데이터를 더 확보하면 개선될 여지가 있습니다.
- 혼동행렬(Confusion Matrix) 상에서는 `사회복지학`과 `사회학` 사이의 오분류가 두드러지는데, 두 분야의 주제·키워드가 서로 유사해 모델도 구분에 어려움을 겪는 것으로 분석했습니다.

> 참고: 별도로 재현한 학습 실행(`classification_report.csv` 기준)에서는 Accuracy 0.9597, Macro F1 0.9448이 나왔습니다. 발표 시점 모델(정확도 0.9691, Macro F1 0.956)과 근소한 차이가 있는데, 랜덤 시드·데이터 분할·epoch 선택 차이에 따른 재현 편차로 보입니다. 실제 값은 각 실행 결과 파일을 기준으로 삽입하세요.
