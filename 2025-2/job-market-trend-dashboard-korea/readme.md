# 全国採用・求職トレンドダッシュボード (Team 수원투용)

全国17市道の求人・求職データ(2022〜2025年)と大韓民国行政区域GeoJSONを組み合わせ、地域別・職種別・学歴別の採用トレンドと需給ギャップを一画面で分析するTkinterベースのデスクトップダッシュボードです。

> ⚠️ 本プロジェクトはStreamlitではなく、**Tkinter + Matplotlibベースのローカルデスクトップアプリケーション**です。Web配布は行わず、ローカル環境で実行する形態であり、今後のWebダッシュボードへの転換計画は「8. 今後の課題」に記載しています。

## 1. 課題定義

採用関連の公共データは年度別・項目別にファイルが分散しており(年度別求人数CSV、年度別求職者数CSV、職種・規模・形態・学歴別統合Excel)、特定の地域・職種・学歴を基準に「求人と求職が実際にどれほどズレているか」を一目で把握することが困難でした。また、年度ごとに列名が異なり(例: 2025年求職データの`학력`↔`나이`列の入れ替わり)、単純にマージするとデータの整合性が崩れる問題がありました。

本プロジェクトは、4カ年分の求人・求職データを一つのパイプラインで統合・整備し、地図可視化・時系列トレンド・職種別規模・学歴別需給ギャップを同時に確認できる分析ツールを作ることを目的としています。

## 2. チーム構成と担当範囲

Team 수원투용のチームプロジェクトとして進行しました。

| 担当者 | 役割 |
|---|---|
| 本人 | ダッシュボードの企画・設計、`app.py`全体のコード実装(データローダー、地図/時系列/職種別/需給ギャップの4分割可視化ロジック、UIフィルター) |
| チームメイト | データ収集(求人・求職・GeoJSONなどの原本データの収集・準備)、発表 |

## 3. データ

- `{年度}_구인인원.csv` (2022〜2025年): 市道・職種・学歴・規模別求人人数
- `{年度}_구직자수.csv` (2022, 2023, 2025年) / `2024_데이터셋.csv`(2024年): 市道・職種・学歴別求職者数
  - 2025年データは`학력`↔`나이`、`규모`↔`학력`の列が入れ替わって提供されており、読み込み時点で列名を再マッピングして整合性を調整
  - 一部の年度は`경력`列を`학력`に統一処理
- `유효구인인원_직종규모형태학력_통합데이터.xlsx`: 全国単位の職種・規模・形態・学歴別統合求人統計
- `skorea-provinces-geo.json`: 大韓民国17市道境界GeoJSON(地図可視化用)

## 4. 使用技術スタック

- **言語/フレームワーク**: Python、Tkinter(GUI)、ttk
- **データ処理**: Pandas、NumPy、openpyxl(Excel読み込み)
- **可視化**: Matplotlib(Figure、FigureCanvasTkAgg)、Matplotlib Polygon/PatchCollection(地図ポリゴン描画)、matplotlib.dates(時系列軸)
- **地理データ**: GeoJSON(大韓民国市道境界)
- **エンコーディング処理**: cp949/utf-8自動フォールバック読み込み(公共データのエンコーディング不一致対応)

## 5. ダッシュボード構成

アプリケーションは左側のフィルターパネルと右側の4分割可視化領域で構成されます。

1. **左側フィルターパネル**: 地域(人口順ソート)、職種、学歴の3重フィルターをコンボボックスで提供し、選択すると即座に全グラフが更新される
2. **全国採用地図(左メイン)**: GeoJSONポリゴンと市道別求人人数を色・バブルサイズで表現し、特定地域を選択するとその地域にズームインする
3. **時期別トレンド(右上)**: 選択した地域・職種・学歴の条件で2022〜2025年の求人/求職人数の月別推移を折れ線グラフで表示
4. **職種別採用規模(右中)**: 全職種中求人人数上位7職種、または選択した職種の採用規模を横棒グラフで表示
5. **学歴別需給ギャップ(右下)**: 学歴別(求職者数 − 求人人数)を算出し、求職者過剰/求人過剰の地域を色で区分

## 6. データ処理における主要な課題と対応

- **年度別スキーマの不一致**: 2025年求職データの列が他の年度と異なって提供されており(`학력`→`나이`、`규모`→`학력`)、読み込み段階で年度別の条件分岐により列名を再整理
- **ファイル欠損への防御ロジック**: 特定年度のファイルがなくてもプログラムが停止しないよう、空のデータフレームに標準列スキーマを事前定義し、後続処理(フィルタリング、groupby)が崩れないよう対応
- **エンコーディング自動判別**: 公共データの特性上cp949/utf-8が混在しているため、try/exceptで2つのエンコーディングを順次試行

## 7. 今後の課題

- ハードコーディングされたローカル絶対パス(`C:\Users\UserPc\Desktop\...`)を相対パスまたは設定ファイル(`.env`、`config.yaml`)に分離し、実行環境への依存性を除去
- TkinterデスクトップアプリをStreamlit/Dashベースのウェブダッシュボードに転換し、配布・共有の容易性を確保
- 市道単位よりも細分化された市区郡単位の分析への拡張
- 統合データ(`유효구인인원_직종규모형태학력_통합데이터.xlsx`)の規模・形態軸を現在は職種フィルタリングのみに活用しているため、規模別/形態別の可視化ページを追加
- リアルタイムまたは定期的なデータ更新の自動化

# 전국 채용·구직 트렌드 대시보드 (Team 수원투용)

전국 17개 시도의 구인·구직 데이터(2022~2025)와 대한민국 행정구역 GeoJSON을 결합해, 지역별·직종별·학력별 채용 트렌드와 수급 불일치를 하나의 화면에서 분석하는 Tkinter 기반 데스크톱 대시보드입니다.

> ⚠️ 본 프로젝트는 Streamlit이 아닌 **Tkinter + Matplotlib 기반 로컬 데스크톱 애플리케이션**입니다. 웹 배포 없이 로컬 환경에서 실행하는 형태이며, 향후 웹 대시보드로의 전환 계획은 "8. 향후 과제"에 명시했습니다.

<!-- 이미지는 추후 첨부 예정 -->

## 1. 문제 정의

채용 관련 공공데이터는 연도별·항목별로 파일이 흩어져 있어(연도별 구인인원 CSV, 연도별 구직자수 CSV, 직종·규모·형태·학력별 통합 Excel), 특정 지역·직종·학력을 기준으로 "구인과 구직이 실제로 얼마나 어긋나 있는가"를 한눈에 파악하기 어렵습니다. 또한 연도마다 컬럼명이 달라(예: 2025년 구직 데이터의 `학력`↔`나이` 컬럼 스왑) 단순 병합 시 데이터 정합성이 깨지는 문제가 있었습니다.

본 프로젝트는 4개년 구인·구직 데이터를 하나의 파이프라인으로 통합·정제하고, 지도 시각화·시계열 추세·직종별 규모·학력별 수급 격차를 동시에 보여주는 분석 도구를 만드는 것을 목표로 합니다.

## 2. 팀 구성 및 담당 역할

Team 수원투용 팀 프로젝트로 진행했습니다.

| 담당자 | 역할 |
|---|---|
| 본인 | 대시보드 기획·설계, `app.py` 전체 코드 구현(데이터 로더, 지도/시계열/직종별/수급 불일치 4분할 시각화 로직, UI 필터) |
| 팀원 | 데이터 수집(구인·구직·GeoJSON 등 원본 데이터 수집·준비), 발표 |

## 3. 데이터

- `{연도}_구인인원.csv` (2022~2025): 시도·직종·학력·규모별 구인 인원수
- `{연도}_구직자수.csv` (2022, 2023, 2025) / `2024_데이터셋.csv`(2024): 시도·직종·학력별 구직자 수
  - 2025년 데이터는 `학력`↔`나이`, `규모`↔`학력` 컬럼이 뒤바뀌어 제공되어, 로드 시점에 컬럼명을 재매핑하여 정합성을 맞춤
  - 일부 연도는 `경력` 컬럼을 `학력`으로 통일 처리
- `유효구인인원_직종규모형태학력_통합데이터.xlsx`: 전국 단위 직종·규모·형태·학력별 통합 구인 통계
- `skorea-provinces-geo.json`: 대한민국 17개 시도 경계 GeoJSON (지도 시각화용)

## 4. 사용 기술 스택

- **언어/프레임워크**: Python, Tkinter(GUI), ttk
- **데이터 처리**: Pandas, NumPy, openpyxl(Excel 로드)
- **시각화**: Matplotlib(Figure, FigureCanvasTkAgg), Matplotlib Polygon/PatchCollection(지도 폴리곤 렌더링), matplotlib.dates(시계열 축)
- **지리 데이터**: GeoJSON(대한민국 시도 경계)
- **인코딩 처리**: cp949/utf-8 자동 폴백 로딩(공공데이터 인코딩 불일치 대응)

## 5. 대시보드 구성

애플리케이션은 좌측 필터 패널과 우측 4분할 시각화 영역으로 구성됩니다.

1. **좌측 필터 패널**: 지역(인구순 정렬), 직종, 학력 3중 필터를 콤보박스로 제공하며, 선택 즉시 전체 그래프가 갱신됩니다.
2. **전국 채용 지도 (좌측 메인)**: GeoJSON 폴리곤과 시도별 구인 인원수를 색상·버블 크기로 표현하며, 특정 지역 선택 시 해당 지역으로 확대(Zoom-in)됩니다.
3. **시기별 추세 (우측 상단)**: 선택한 지역·직종·학력 조건에서 2022~2025년 구인/구직 인원의 월별 추이를 라인 차트로 표시합니다.
4. **직종별 채용 규모 (우측 중단)**: 전체 직종 중 구인 인원 상위 7개 직종, 또는 선택한 직종의 채용 규모를 가로 막대로 표시합니다.
5. **학력별 수급 불일치 (우측 하단)**: 학력별 (구직자 수 − 구인 인원)을 계산해, 구직자 과잉/일자리 과잉 지역을 색상으로 구분합니다.

## 6. 데이터 처리 관련 주요 이슈 및 해결

- **연도별 스키마 불일치**: 2025년 구직 데이터의 컬럼이 다른 연도와 다르게 제공되어(`학력`→`나이`, `규모`→`학력`), 로드 단계에서 연도별 조건 분기로 컬럼명을 재정렬함.
- **파일 부재 방어 로직**: 특정 연도 파일이 없어도 프로그램이 죽지 않도록, 빈 데이터프레임에 표준 컬럼 스키마를 미리 정의해 후속 처리(필터링, groupby)가 깨지지 않게 처리.
- **인코딩 자동 판별**: 공공데이터 특성상 cp949/utf-8이 혼재되어 있어, try/except로 두 인코딩을 순차 시도.
